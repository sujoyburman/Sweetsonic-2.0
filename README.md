## SweetSonic 2.1 — BioTune™ homepage update

This development build branches from the frozen public SweetSonic 2.0 baseline. It adds a prominent BioTune™ feature directly below the homepage hero, a BioTune™ navigation link, a visual sound-frequency motif, and an upfront aspiration/transparency statement. Existing Academy, Studio, Service and other page content is retained.

BioTune™ is explicitly described as an exploratory concept in development. The website does not claim that BioTune™ is a validated medical device, treatment, diagnostic tool or cure. Proposed sensing/adaptive features remain subject to product definition, development and validation.
